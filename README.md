Dr. Hackathon — 

Dr. Hackathon is a next-generation, open-source developer and cybersecurity environment built on the Termux foundation. It transforms Android—and potentially PC—into a powerful, modular development workspace combining a Linux terminal, code editor, package manager, plugin ecosystem, AI agents, Web Search, virtualization, and professional development and security tools.

Users can extend the environment through an @plugin system, installing programming languages, compilers, Git, QEMU, networking utilities, authorized cybersecurity tools, AI agents such as OpenCode, PicoClaw and ANI-CLI, and hundreds of other tools on demand.

With Bring Your Own API, local AI support, integrated Web Search, Linux environments, Android development tools, SSH, Git, file management, system monitoring, and a modern cyber-focused interface, Dr. Hackathon aims to turn a mobile device or PC into a complete developer command center.
